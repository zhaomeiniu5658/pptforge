# Quarkmed 夸克医药 · PPT/HTML 方案智造平台

## 已批准的实现范围

独立 React/TypeScript 工作台，FastAPI API，PostgreSQL 业务数据库。界面以 docs 下三角色原型为准，不 Fork OpenStitch 产品前台。一般人员通过内嵌 AI 设计窗口进行文字、截图生成及页面修改；所有结果先为候选，采用后成为页面版本。

管理员维护八类模板、部门和用户，上传 PPTX、检查转换并发布；商务两步立项、分工、审核、合订；一般人员仅编辑分配分册。提交冻结版本，正式合订只使用通过审核的提交。HTML/ZIP 为首版交付，连续长页面为主，PPTX 导出后置。

## 数据与服务边界

API 管理用户、部门、项目、模板、页面版本、提交、审核、资源、任务、导出、审计。Celery/Valkey Worker 执行生成和 PPTX 转换。Node 工具层负责 HTML/CSS 规范化、浏览器渲染、像素比较和单 DOM 合订。模型密钥仅在后端。

统一 HtmlPageDocument 保存 html/css/assets/interactions/layoutMode/sourceSize/editableNodes/sourceReferences/diagnostics。稳定节点 ID 支持编辑。源 PPTX 保留，基础文字和图片转 HTML，复杂组合优先图像保真并明确不可编辑范围；严重问题阻止发布。

## 验收

权限越权拒绝；同文案单节点编辑；版本冲突 409；提交不随草稿变化；未审通过无法正式导出；CSS/ID/动画隔离；资源随 HTML/ZIP 交付；AI 取消与未采用不覆盖草稿；PPTX 转换诊断不冒充完全可编辑；关闭浏览器后任务与草稿可恢复。

实现与当前验证状态见 README.md 和 docs/implementation/verification.md。GMP/21 CFR Part 11 完整验证、可编辑 PPTX 导出、实时多人协作不属于首版。
